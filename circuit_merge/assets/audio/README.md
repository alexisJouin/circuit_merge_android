# Musique principale

Placer le morceau choisi dans ce dossier sous le nom `main_theme.mp3` (ou `main_theme.ogg`, prioritaire).

La piste est lue en boucle et en streaming, à 35 % du volume. Le bouton Son contrôle la musique et les effets. Le passage en arrière-plan suspend la piste ; le retour reprend sa position si le son est activé. La piste peut être remplacée sans changer le code.

État de cette modification : l'intégration est prête, mais le MP3 fourni (TD / Tetsuo Dance, Chu Ishikawa) n'a pas pu être téléchargé dans l'environnement de travail et n'est pas inclus. Sans fichier, le jeu conserve ses effets sonores.
